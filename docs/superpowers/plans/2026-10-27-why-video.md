# why-video 科普视频生成 skill 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 做一个 Claude Code skill：输入小朋友的"为什么"问题，研究后写脚本分镜，经 Robert 确认，调 SiliconFlow 生成视频片段与 TTS 旁白，ffmpeg 合成竖屏科普短视频。

**Architecture:** 两件东西。SKILL.md 负责编排（研究、写脚本分镜、确认关卡、返工指挥）；单文件 `pipeline.py`（约 300 行，三个子命令 `verify` / `generate` / `assemble`）负责一切烧钱和确定性工作：能力验证、TTS、视频提交轮询、断点续跑、ffmpeg 合成。机器状态存在每个项目目录的 `storyboard.json`。

**Tech Stack:** Python 3.11+（复用 backend/.venv：httpx、pytest）、SiliconFlow API（Wan 视频 + CosyVoice TTS）、ffmpeg/ffprobe（brew 安装，需 subtitles 滤镜）。

**Spec:** `docs/superpowers/specs/2026-10-27-why-video-design.md`

## Global Constraints

- skill 目录：`.claude/skills/why-video/`，内含 `SKILL.md`、`pipeline.py`、`tests/test_pipeline.py`。
- API key：环境变量 `SILICONFLOW_API_KEY` 优先，否则读 `backend/.env.local` 的 `LLM_API_KEY`；不得硬编码、不得打印。
- 成片规格：1080x1920 (9:16)，H.264 + AAC，MP4；字幕烧录进画面。
- 产物目录：`output/why-videos/<YYYYMMDD>-<slug>/`（`output/` 进 .gitignore）。
- 运行与测试（仓库根目录）：`backend/.venv/bin/python .claude/skills/why-video/pipeline.py <子命令>`；`backend/.venv/bin/python -m pytest .claude/skills/why-video/tests -v`。
- 能力验证失败 / 无竖屏模型时：停下报告 Robert，不自行降级（spec 第 0 步）。
- 代码注释与面向 Robert 的输出一律中文。
- 与 spec 文字的一处偏离（交付时已向 Robert 说明）：脚本/旁白由会话中的 Claude 直接撰写，不经 DeepSeek API；SiliconFlow 只承担视频与 TTS。

## Review Focus

spec 隐含、最可能咬人的输入，测试归属已标注：

1. 问题含非法文件名字符（"……是圆的？"）→ slug 只含安全字符 → Task 1。
2. 旁白混数字/英文（"8000公里"）→ 字幕分行不得从数字中间断开、无空行 → Task 1。
3. 中断后重跑 → done 的分镜跳过，不重复扣费 → Task 1。
4. 轮询超时/任务失败 → 该分镜标 failed、继续其余、结束汇总，不无限等待 → Task 2。
5. 生成片段分辨率不符合预期 → assemble 统一 scale+pad 到 1080x1920 而不是报错 → Task 2。

  - `save_board(path: Path, data: dict)` / `load_board(path: Path) -> dict` — JSON 原子写（临时文件 + rename）
  - `storyboard.json` schema 固定在模块 docstring：`{question, slug, created, voice, video_model, scenes: [{id, narration, visual_zh, visual_prompt_en, status: pending|audio_done|done|failed, audio_file, clip_file, audio_duration, error}]}`

### Task 2: pipeline.py 外部环节 —— verify / generate / assemble

**Files:**
- Modify: `.claude/skills/why-video/pipeline.py`
- Test: `.claude/skills/why-video/tests/test_pipeline.py`（追加）

**Interfaces:**
- Consumes: Task 1 全部函数
- Produces:
  - 内部：`_request(method, path, api_key, json=None) -> dict`（httpx，base `https://api.siliconflow.cn/v1`；全部 HTTP 收敛于此便于 mock）；`class VideoGenError(RuntimeError)`；`tts_to_file(...) -> float`（POST `/audio/speech` 落盘 mp3，ffprobe 得时长）；`submit_video(...) -> str` + `poll_video(request_id, timeout_s=900, interval_s=10) -> str`（POST `/video/submit` / `/video/status`；失败/超时抛 VideoGenError）；端点若与 SiliconFlow 现行文档不符，以 verify 真机实测为准修正
  - 常量区：`TTS_MODEL = "FunAudioLLM/CosyVoice2-0.5B"`、`DEFAULT_VOICE`（验证后定亲切音色）、`VIDEO_SIZE = "720x1280"`、`EST_PER_CLIP_YUAN`（验证后按所选模型填）
  - 子命令（argparse）：
    - `verify [--full]`：key、ffmpeg/ffprobe 及 subtitles 滤镜、GET `/models` 视频+TTS 清单，逐项 ✅/❌ 中文报告；`--full` 加一句试音 TTS + 一段最便宜竖屏测试片（打印花钱提示）。缺失退出码 1
    - `generate <project_dir> [--redo 1,3] [--yes]`：scenes_todo → 打印成本预估（N 段 × EST_PER_CLIP_YUAN）→ 无 --yes 需输入 y → 逐分镜 TTS（→audio_done）→ 视频提交轮询下载（→done），每步后 save_board；VideoGenError 自动重试 1 次（重新 submit），再失败才标 failed 记 error 并继续下一段；结束打印汇总，有 failed 退出码 1
    - `assemble <project_dir>`：校验全部 done（否则中文报错退 1）→ build_srt 写 subs.srt → 每分镜 ffmpeg 归一（scale=1080:1920:force_original_aspect_ratio=decrease + pad；视频短于音频 tpad=stop_mode=clone 定格，长则截断）→ concat demuxer 拼接 → subtitles 滤镜烧字幕（大号白字黑描边、底部 1/5）→ `final.mp4`，打印路径与总时长

  1. 首次使用先跑 `verify`；不通过 → 停下报告，附 `brew install ffmpeg` 指引
  2. 第一幕：WebSearch 查证（至少两个来源互证）→ 以 4-8 岁孩子的讲故事语气写旁白（引导→铺垫→比喻→温暖收尾，长度以讲清楚为准，每分镜 15-35 字）→ 拆分镜（visual_zh 给 Robert 看 + visual_prompt_en 给模型，prompt 统一追加 bright, warm, child-friendly, gentle 风格词，规避黑暗/恐怖意象）
  3. **确认关卡（硬性）**：展示旁白全文 + 分镜表 + 预计时长与成本，等 Robert 修改/确认；确认前禁止任何生成调用
  4. 确认后：建 `output/why-videos/<YYYYMMDD>-<slug>/`，写 `script.md`（确认版）+ `storyboard.json`，跑 `generate`、`assemble`
  5. 交付：报告 final.mp4 路径、总时长、实际消耗（几段、几次失败重试）
  6. 返工："重做第 N 段" → 按 Robert 要求更新该分镜字段 → `generate <dir> --redo N` → `assemble <dir>`
  7. 全程中文；命令一律 `backend/.venv/bin/python .claude/skills/why-video/pipeline.py ...`
