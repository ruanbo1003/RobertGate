# AI Tools PRD

## 概述
一个供本人/家人使用的私人 AI 工具集合页，左侧固定 sidebar 导航 + 右侧主内容区，集成翻译/英文优化、小孩英文启蒙、小孩汉字学习、文生图四个工具。

## 目标用户
- **用户画像**：站点所有者本人和家人（含小孩）
- **核心诉求**：
  - 高频：快速完成中英翻译与英文表达优化
  - 低频高停留：陪伴小孩进行英文/汉字启蒙学习
  - 偶发创意：文字描述生成图片

## 使用场景
1. 工作中需要把中文邮件翻译成地道英文，或检查英文语法 → 用「翻译/英文优化」
2. 家长录入想让孩子学的一批汉字，孩子在「逐字学习」逐个看动画并标记已学，再用「句子学习」复习
3. 孩子打开「英文启蒙」选个主题（颜色/动物/形状/水果），听单词发音点对图片，玩 10 题一轮
4. 一时兴起用 prompt 生成一张图存本地

## 交互设计

### 通用状态
- **加载态**：按钮内 spinner + 文案变「生成中...」+ 按钮禁用；长任务用整页居中 spinner
- **空状态**：灰色插画/emoji + 一句话引导 + CTA 按钮
- **错误态**：红色 inline banner，含「重试」；保留用户输入，不清空
- **需登录**：弹出 `LoginModal`，保留当前操作意图，登录完接着做，不强制跳转

### 关键交互
- **Sidebar 二级菜单**：点工具名展开/收起；选中子页时父菜单保持展开
- **翻译复制反馈**：点「复制」按钮 → 图标变 ✓ + 文字「已复制」→ 2 秒后还原
- **翻译结果不累积**：每次点动作按钮覆盖上一次结果（不留历史）
- **字库添加去重**：粘贴文本时提取所有汉字，已存在的字给「已在字库中」提示
- **逐字学习自动推进**：点「已学完 ✓」后自动跳到下一未学字
- **英文启蒙答错允许重试**：红叉动画 ~800ms 后题目仍可点，直到答对才进入下一题
- **TTS 自动播放**：英文启蒙进入题目自动播一次单词
- **笔顺动画**：进入逐字学习自动播一次；点画布重播

### 动效规范
- 时长 150ms ~ 400ms
- 缓动 `ease-out`
- 按钮 hover：`scale-[1.01]`
- 表单/输入 focus：蓝色 ring

## 边界情况

| 情况 | 处理方式 |
|------|---------|
| 翻译输入为空 | 三个按钮置灰 |
| 翻译 API 失败 | inline 错误 + 「重试」按钮；输入保留 |
| 字库为空时进入逐字学习 | 空状态：「字库还没有字，先去字库添加」+ CTA |
| 字库 < 5 字进入句子学习 | 提示「先学几个字再来组句」 |
| 句子学习 AI 返回库外字 | 库外字红色高亮，不阻塞 |
| 全部字已学完 | 完成提示 + [回字库] [重置进度] |
| 英文启蒙某主题无图（图未生成完） | 主题卡显示「准备中」，不可点击 |
| 文生图生成失败 | 红色提示 + 「重试」；prompt 不清空 |
| 用户未登录就操作字库 | 弹出登录 modal；登录后继续操作 |
| Sidebar 二级菜单全部收起后点击父项 | 直接跳到该工具的第一个子页 |

## 设计约束

引用 `.claude/rules/ui-style.md`：

- **配色**：仅使用 Tailwind config 中的 token（`primary`、`accent`、`bg`、`card`、`text-primary`、`text-muted`、`border`、`error`、`success`），禁止硬编码 hex
- **字体**：统一 Plus Jakarta Sans
- **圆角**：卡片 16px
- **阴影**：`shadow-sm` + `shadow-[0_8px_32px_rgba(0,0,0,0.08)]`
- **按钮高度**：44px
- **背景纹理**：48px 网格线，opacity 0.4
- **组件复用**：优先复用 `src/components/` 已有共享组件

## 技术备注

### 后端接口
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/v1/ai/translate` | 翻译/优化（参数：`text`, `action`：translate/grammar/native） |
| POST | `/api/v1/ai/sentence` | 给一组字生成句子 |
| POST | `/api/v1/ai/character-info` | 给单字返回拼音/组词/例句 |
| POST | `/api/v1/ai/text-to-image` | 文生图 |
| GET  | `/api/v1/hanzi/library` | 查字库（含已学状态） |
| POST | `/api/v1/hanzi/library` | 批量加入字库（去重） |
| PATCH | `/api/v1/hanzi/library/:char` | 标记已学/未学 |
| DELETE | `/api/v1/hanzi/library/:char` | 删除单字 |
| GET  | `/api/v1/english/themes` | 主题列表 + 词列表 + 图片 URL |
| POST | `/api/v1/english/quiz` | 随机出题（返回 1 词 + 4 图 URL，含正确标记） |

### 数据存储
- 字库（含已学状态）：后端数据库，需登录
- 英文启蒙主题/词/图：预生成存于 `/root/images` 目录，元数据存数据库
- 翻译记录：不存
- 文生图记录：暂不存（P1 考虑）

### 三方依赖
- `hanzi-writer`：汉字笔顺动画
- 浏览器原生 `SpeechSynthesis`：TTS 朗读，封装为 `useSpeech` hook

### 路由结构
```
/ai-tools/translate
/ai-tools/hanzi/library
/ai-tools/hanzi/learn
/ai-tools/hanzi/sentence
/ai-tools/english/themes
/ai-tools/english/quiz?theme=colors
/ai-tools/text-to-image
```

### AI 模型
- 后端写死调用某个大模型 API（OpenAI / Claude / Gemini / 国产，由后端实现时确定）
- 前端不感知模型差异，统一走 `/api/v1/ai/*` 接口
