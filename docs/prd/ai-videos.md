# AI Videos（英语启蒙短视频工作台）PRD

## 概述

一个可视化、可干预、可复用的 AI 视频创作工作台：以固定角色 IP 为核心，通过「剧本 → 分镜 → 分镜图 → 图生视频 → 配音字幕 → 合成」流水线，产出 30-120 秒竖屏（9:16）英语启蒙情景短剧，发布到抖音 / 视频号 / 小红书。

## 目标用户

- **用户画像**：Robert 本人（开发者、专业用户），单用户使用
- **核心诉求**：
  - 把现有 why-video 式终端流水线升级为可视化网页工作台
  - 全程可干预：每一步可编辑、单镜可重做、失败不连坐
  - 角色 IP 可复用，支撑系列化产出
  - 专业参数全暴露：模型选择、prompt 编辑不设限

内容消费者为学英语启蒙阶段的小朋友，形态为**角色对话小剧情**（多固定角色、简单重复对白）。

## 使用场景

1. **日常产出**：晚上想做一集「水果主题」→ 选角色 → 输入梗概 → AI 出剧本 → 快速编辑确认 → 批量生成 → 次日回来查看成片，失败的分镜单独重做。
2. **单镜精修**：第 5 镜画面崩了，只重新生成该镜的图和视频，其他镜不动。
3. **系列化管理**：同一组角色出 N 集，在项目列表查看每集状态（草稿 / 生成中 / 部分失败 / 已完成），在角色库查看每个角色被哪些集引用。

## 功能需求

### P0（必须实现）

**模块一：角色库**
- [ ] 角色列表页：卡片网格展示设定图 + 名字 + 一句话设定 + 「已用于 N 集」角标
- [ ] 角色创建/编辑：名字、外形描述（英文 prompt）、性格设定 → 调 SiliconFlow 文生图生成设定图；可选模型、可改 prompt、可重 roll 多张选一张设为封面
- [ ] 角色删除保护：被视频引用的角色禁止删除，提示引用列表

**模块二：视频项目**
- [ ] 项目列表页：卡片网格，9:16 封面缩略图 + 标题 + 状态角标（草稿 / 生成中 / 部分失败 / 已完成）
- [ ] 创建向导（3 步）：主题/故事梗概 → 选角色（多选）+ 目标时长 + 默认模型 → LLM 生成剧本并编辑确认 → 自动拆分镜落入工作台

**模块三：创作工作台（分镜中心式，桌面端专用）**
- [ ] 剧本阶段：LLM 生成英文对白剧本（用词适配启蒙难度），全文可编辑；改剧本后可选择「重新拆分镜」
- [ ] 分镜管理：每镜含画面 prompt、出场角色、台词、预估秒数；可编辑 / 增删 / 拖拽排序
- [ ] 分镜图生成：逐镜文生图，**带角色参考图**（图生图/参考图模式）；每镜独立选模型、改 prompt、单独重做
- [ ] 图生视频：逐镜图生视频，单镜级模型选择与重试
- [ ] 配音：英文台词 TTS（SiliconFlow CosyVoice）
- [ ] 字幕：整句底部英文字幕（烧录进成片）
- [ ] 合成：后端 ffmpeg 拼接镜头 + 配音 + 字幕 → MP4，工作台内预览 + 下载
- [ ] 单镜预览：当前选中镜的图 / 视频 / 音频预览（整集粗剪预览降为 P1，整集效果以合成结果为准）

**模块四：任务与容错**
- [ ] 分步状态机：每镜的图 / 视频 / 音频独立状态（待生成 / 生成中 / 成功 / 失败 / 过期），失败只重试失败项
- [ ] 异步任务 + 进度展示：批量生成排队执行，页面展示「第 8/15 镜生成中」；关闭页面后台继续，回来状态还在

### P1（优先级次之）

- [ ] BGM：背景音乐，音量压低不盖人声
- [ ] 角色音色绑定：每个角色固定一个 TTS 音色
- [ ] 双语字幕：英文大字 + 中文小字
- [ ] 成本统计：每集 API 调用次数 / 费用
- [ ] 剧本模板：沉淀常用剧情模板（打招呼、逛超市…）
- [ ] 一键重生成整集：剧本不变，全部画面重 roll
- [ ] 整集粗剪预览：已生成镜头按顺序串播

## 页面布局

路由挂在已有的顶部导航「AI Videos」（`/ai-videos`）下：

1. **项目列表页** `/ai-videos`：页头（标题 + 「新建视频」主按钮）+ 响应式卡片网格；卡片为 9:16 竖版封面 + 标题 + 状态角标 + 更新时间。
2. **角色库页** `/ai-videos/characters`：同构卡片网格；新建/编辑为全屏弹层——左侧参数表单（名字 / prompt / 模型），右侧生成结果画廊（多图选一）。
3. **创作工作台** `/ai-videos/:projectId`（桌面端专用，占满视口的三栏 IDE 式布局；移动端显示「请在桌面打开」提示）：
   - **左栏（~280px）分镜轨道**：每镜小卡 = 缩略图 + 镜号 + 三个状态点（图 / 视频 / 音频；绿=成功、红=失败、灰=待生成、蓝=进行中呼吸动画、黄=过期）；支持拖拽排序、增删
   - **中栏（主区）单镜编辑**：画面 prompt、台词、出场角色（角色参考图头像）、文生图 / 图生视频模型下拉、生成 / 重做按钮、产物预览（图 / 视频 tab）
   - **右栏（~320px）全局面板**：9:16 单镜预览框、「批量生成全部」「合成成片」「下载」、整体进度（「视频 8/15 完成，2 失败」）
   - **顶部工具栏**：返回列表、项目标题、「剧本」按钮（侧滑抽屉查看 / 编辑剧本，可触发重新拆分镜）

**创建流程**：新建走 3 步轻量向导，剧本确认后自动拆分镜进入工作台；再次打开已有项目直接进工作台。

## 交互设计

- **加载态**：向导中 LLM 生成剧本时骨架屏 + 可取消；生成中的镜状态点呼吸动画（primary 蓝）；列表页骨架卡片
- **空状态**：角色库空 → 引导「先创建第一个角色」；项目空 → 「创建第一集视频」；分镜无产物 → 显示生成按钮占位
- **错误态**：失败状态点置红，点击可展开查看原始报错信息；全局性错误（余额不足 / Key 失效）暂停整个队列并在工作台顶部横幅报错
- **hover**：分镜卡浮起 + 快捷操作（重做图 / 重做视频 / 删除）；项目 / 角色卡浮起 + 阴影加深
- **确认弹窗**：删除项目 / 分镜 / 角色（红色 destructive 按钮）；视频重做前确认（防误触浪费费用）；合成前列出所有「过期」项供确认

## 边界情况

- **过期链（上游修改）**：剧本→分镜→图→视频、台词→音频/字幕存在依赖。改上游后**下游产物标记黄色「过期」但保留**，仍可预览和用于合成；合成时弹确认框列出全部过期项，是否重做由用户决定。
- **重做覆盖**：所有产物重做即覆盖，不保留历史版本；视频重做前弹确认。
- **台词时长 vs 视频时长不匹配**：双保险——① 拆分镜时 LLM 控制每镜台词为一句短句（目标落在单段视频时长内，超长拆两镜）；② 合成时以音频时长为准，视频不足则末帧定格补齐。
- **生成失败**：不做自动重试，失败置红，由用户手动点重做（纯手动策略）。
- **批量生成并发**：保守默认（图并发 2、视频并发 1），串行排队，进度条展示队列；后续按实际限流调整。
- **多角色同镜**：参考图仅喂主要角色一张，prompt 中补全所有角色外形描述（接受的妥协）。
- **角色被引用时删除**：禁止，提示引用的视频列表。
- **生成中修改 prompt**：允许编辑，但进行中任务按旧参数完成，完成后产物立即标记「过期」。
- **合成失败（ffmpeg）**：合成状态独立，失败可查看日志并重试，不影响已有分镜产物。

## 设计约束

遵循 `.claude/rules/ui-style.md`：

- 配色：primary `#2563EB`（主操作 / 进行中）、success `#16A34A`（成功）、error `#DC2626`（失败）、warning `#D97706`（过期角标）、bg `#F8FAFC`、card `#FFFFFF`、border `#E2E8F0`；禁止硬编码，全部走 Tailwind token
- 字体：Plus Jakarta Sans 全站统一
- 卡片：16px 圆角 + 轻阴影；按钮高 44px（工作台内密集操作区可用紧凑尺寸）
- 动效：150-400ms ease-out
- 工作台为占满视口的三栏布局，是对现有居中卡片式视觉语言的扩展，token 全部复用
- 响应式：列表页 / 角色库响应式；工作台仅桌面端，移动端显示提示页

## 技术备注

- **供应商**：全部走 SiliconFlow 统一 Key（复用现有配置）；LLM（剧本/拆分镜，模型可选，默认 DeepSeek-V3 级别）、文生图（需支持参考图的模型优先）、图生视频、TTS（CosyVoice）均模型可选
- **存储**：产物（图 / 视频 / 音频 / 成片）存后端本地磁盘（如 `backend/data/ai-videos/`），数据库仅存路径；单集约 50-200MB
- **任务状态同步**：前端简单轮询（2-3 秒间隔拉取项目状态），第一版不上 WebSocket/SSE；后端任务队列需在进程内常驻，页面关闭不中断
- **API**（统一前缀 `/api/v1`，返回格式遵循 `.claude/rules/api.md`）：
  - `GET/POST/PUT/DELETE /ai-video-characters` 角色 CRUD + `POST /ai-video-characters/{id}/generate-image` 设定图生成
  - `GET/POST/DELETE /ai-video-projects` 项目 CRUD
  - `POST /ai-video-projects/{id}/script` 剧本生成 / 更新、`POST .../shots/split` 拆分镜
  - `GET/PUT/POST/DELETE .../shots/{shotId}` 分镜 CRUD + 排序
  - `POST .../shots/{shotId}/image|video|audio` 单镜生成；`POST .../generate-all` 批量；`POST .../compose` 合成
  - `GET /ai-video-projects/{id}/status` 轮询用聚合状态
  - `GET /ai-video-models?type=t2i|i2v|llm|tts` 可用模型列表
- **核心数据实体**：Character（名字 / prompt / 设定 / 封面图 / 候选图）、Project（标题 / 梗概 / 角色关联 / 时长 / 状态 / 剧本）、Shot（序号 / 画面 prompt / 台词 / 角色 / 图・视频・音频产物路径 + 各自状态 + 过期标记）、Task（类型 / 目标 / 状态 / 错误信息）
- **路由与鉴权**：前端 `/ai-videos`（当前指向 NotImplementedPage，需替换）、`/ai-videos/characters`、`/ai-videos/:projectId`；与 `/ai-tools` 一致走 ProtectedRoute
